ghir.owners#

Owner logins -> repo records, stdlib only (no ir, no dol).

The reusable half of ghir.fetch: a GraphQL transport seam (graphql=, a callable (query, variables) -> dict; gh_graphql() shells out to the gh CLI, urllib_graphql() needs only a token), "@me" expansion, fnmatch exclusion and cursor pagination that backs off the page size on gateway errors. What a record contains is a seam too: fields is the GraphQL selection and normalize flattens a node, so ghir asks for README blobs while another collector asks for permissions and fork counts.

>>> expand_owners(["@me", "acme", "bob"], me=lambda: ["bob", "org1"])
['bob', 'org1', 'acme']
>>> is_excluded("Acme/x", ["acme/*"]), is_excluded("bob/x", ["acme/*"])
(True, False)
>>> def fake(query, variables):
...     return {"repositoryOwner": {"repositories": {
...         "pageInfo": {"hasNextPage": False, "endCursor": None},
...         "nodes": [{"nameWithOwner": "acme/x"}, {"nameWithOwner": "acme/y"}]}}}
>>> [r["nameWithOwner"] for r in list_repos(["acme"], graphql=fake, exclude=["acme/y"])]
['acme/x']

Yield a record per repo over owners ("@me" expanded), minus exclude.

normalize maps a node to the record (default: the node itself). An owner pattern in exclude ("acme/*") also stops that owner being queried. An owner whose listing fails goes to on_error(owner, error) and is skipped, or, when on_error is None, the error propagates.

ghir.owners.owner_is_excluded(owner, exclude)[source]#

Whether some pattern of exclude matches every repo of owner.

Only a pattern ending in * whose head matches "<owner>/" does ("acme/*", "*/*"); "acme/?" or "acme/[!l]*" exclude only some of acme’s repos, so acme must still be listed.

>>> owner_is_excluded("Acme", ["acme/*"]), owner_is_excluded("acme", ["acme/?"])
(True, False)
Return type:

bool
