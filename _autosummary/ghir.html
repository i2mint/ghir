ghir#

Search your GitHub repos, cloned or not, as an ir corpus.

Four seams, each a keyword argument with a working default:

  • locations (refresh()): owner logins, "@me" (you and your orgs), or "search:<github query>".

  • extraction (extract=): what text a repo contributes; default description + topics + README head (ghir.extract).

  • ranking (rank=): "ir" (default, hybrid dense + BM25) or "grep".

  • cache (store=): a MutableMapping; refresh() merges into it, search() only reads it (offline).

>>> import ghir
>>> ghir.refresh()
>>> for hit in ghir.search("flashcards spaced repetition"):
...     print(hit.id, hit.local_path)

ghir.fetch_repos(locations, *, exclude=(), graphql=<function gh_graphql>, owners=<function my_owners>, on_error=None)[source]#

Yield repo records over all locations, skipping excluded repos.

A location whose fetch fails is passed to on_error(location, error) and skipped, or, when on_error is None, the error propagates.

An owner pattern in exclude ("Acme/*") also stops that owner from being queried at all, so nothing of it is fetched.

ghir.refresh(locations=None, *, store=None, exclude=None, fetch=<function fetch_repos>, **fetch_kwargs)[source]#

Fetch the repos of locations and merge them into the cache.

Returns counts: {"fetched", "added", "updated", "kept"} where kept is the number of cached records this fetch did not see (and left alone), plus "failed": {location: error} for locations that could not be fetched (their cached records are kept), and "purged": cached records removed because they are now excluded (by exclude or local_exclude).
